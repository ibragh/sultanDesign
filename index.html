Redesign concepts · sh.apartment · Jeddah

Five directions for the sh.apartment website

Every concept uses the real seven apartments, their own photos from the Airbnb listings, and the real ratings: 4.83 from 517 reviews. Three concepts follow the landing-page-design skill to the letter. Two are original ideas. All are Arabic first and fully clickable.

Placeholders: nightly prices are examples until the owners set them. No guest review quotes were invented. Where a design shows a quote card, it is labelled as a sample to replace with a real Airbnb review.

Where it starts

The current site has more under the hood than it shows. It already syncs each apartment’s calendar with Airbnb, takes direct bookings with a signed contract, and hands off to WhatsApp. The design hides most of that.

Keep

  • The illustrated Jeddah with a live sky: memorable and local
  • Direct booking with an e‑signed contract
  • Two‑way calendar sync with Airbnb
  • WhatsApp as the last step

Fix

  • No photos, though the interiors are the selling point
  • No prices or totals before committing
  • Ratings show 0.00 while they load
  • Booking is hidden inside accordions
  • Mixed Arabic and English names, no beds or guest counts
  • The owner dashboard is the biggest button on a guest page

The second question

Can the site connect to Airbnb and Gathern?

Airbnb: it already does. Gathern: yes, the same way.

Their site already reads each apartment’s Airbnb calendar through an iCal (.ics) link, and gives Airbnb a link back. A night booked anywhere is blocked everywhere. Gathern can join that loop if it accepts the same kind of link.

Today · working

Airbnb over iCal

The owner dashboard stores each apartment’s Airbnb export link and shows an import link to paste into Airbnb. One limit: Airbnb refreshes imported calendars about every 3 hours. A direct booking can therefore take up to 3 hours to block the night on Airbnb.

Next · Gathern

Add Gathern the same way

  1. Ask their Gathern account manager: “Can I import and export my calendar as an iCal (.ics) link?”
  2. If yes, add a Gathern import link next to the Airbnb one in the dashboard, and paste the site’s export link into Gathern.
  3. Add an “Open on Gathern” button to each apartment.

Gathern’s public pages don’t describe calendar sync. Saudi tools such as Naseeq list Gathern next to Airbnb in their iCal sync, so it looks likely.

Later · if it grows

A channel manager

Tools such as Hostaway, Guesty or Hospitable connect to Airbnb through its official API. They sync prices and messages too, within minutes rather than hours. They cost a monthly fee per unit, and none of the big ones we checked list Gathern. With seven units, the current setup plus Gathern over iCal is enough.

Why direct bookings matter

Airbnb now charges most hosts a single fee of about 15.5% of each booking. A direct booking keeps that amount. Some of it can go back to the guest as a lower direct price, which is the case concepts 1 and 2 make.

Fix first: the owner dashboard PIN

The page checks the owner’s PIN in the browser. The public page source holds a hash of it, and a short number can be cracked from that hash in seconds. If the server uses the same PIN, anyone could then open the dashboard, see guests’ names and phone numbers, and cancel bookings.

The fix: remove the hash from the page, check the password only on the server (the Worker already checks it there), use a long passphrase instead of a short number, and limit login attempts. I didn’t try to break it. I only read the public page source.

Also worth doing

  • Store the apartment list on the server, next to the bookings it already stores, so the owner’s edits go live without downloading and uploading the page again.
  • Show each unit’s Ministry of Tourism license number on its page. Airbnb already requires one in Saudi Arabia.
  • Add online payment for direct bookings through a Saudi gateway such as Moyasar, Tap or HyperPay (mada, Apple Pay, STC Pay).
  • Put the owner login on its own address, away from the guest page.
